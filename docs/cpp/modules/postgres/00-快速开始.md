# 00-快速开始

## 构建

```bash
cmake -S . -B build \
  -DGALAY_BUILD_POSTGRES=ON \
  -DBUILD_TESTING=ON \
  -DGALAY_BUILD_EXAMPLES=ON \
  -DGALAY_BUILD_BENCHMARKS=ON
cmake --build build --parallel
```

依赖为 C++23、`galay-kernel` 和 `galay-utils`；基础库不依赖 `libpq`。

## 环境

真实服务测试、示例与压力基准读取：

- `GALAY_POSTGRES_HOST`
- `GALAY_POSTGRES_PORT`
- `GALAY_POSTGRES_USER`
- `GALAY_POSTGRES_PASSWORD`
- `GALAY_POSTGRES_DB`

测试配置头还接受等价的 `GALAY_POSTGRES_TEST_HOST/PORT/USER/PASSWORD/DATABASE` 变量；以实际测试环境使用的那组为准。

## 测试

```bash
ctest --test-dir build -L postgres -LE integration --output-on-failure
ctest --test-dir build -L requires-postgres --output-on-failure
```

缺少集成环境时，集成测试以返回码 `125` 标记 skipped。
