# 07-常见问题

## 为什么查询错误后还要等 ReadyForQuery？

PostgreSQL 以 `ReadyForQuery` 标记请求周期结束；提前复用连接会把上一请求残留消息误配给下一请求。

## NULL 和空字符串如何区分？

DataRow 中长度 `-1` 是 NULL，长度 `0` 是空值。API 分别返回 `std::nullopt` 和存在但为空的字符串。

## 为什么没有 libpq 依赖？

模块自行实现 wire protocol，以保持与 galay 其他协议模块一致。benchmark 可选链接 libpq 进行对比。

## SCRAM-SHA-256-PLUS 是否支持？

不支持。它依赖 TLS channel binding，与 TLS 一起留待独立实现。

## 集成测试为何 skipped？

检查 `GALAY_POSTGRES_TEST_HOST/PORT/USER/PASSWORD/DATABASE`。缺失真实 PostgreSQL 配置时测试返回 `125`，CTest 会显示 skipped。示例和 benchmark 使用不带 `TEST_` 的 `GALAY_POSTGRES_HOST/PORT/USER/PASSWORD/DB`。
