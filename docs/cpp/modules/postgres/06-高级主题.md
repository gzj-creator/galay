# 06-高级主题

## 协议限制

普通消息长度字段包含自身四字节、不包含 type；startup 消息没有 type，最大为 10000 字节。全部整数采用大端编码。

SCRAM 校验要求服务端 nonce 扩展客户端 nonce，Base64 必须是 canonical encoding，服务端签名使用完整字节比较。密码字节按调用方提供值使用，当前不执行 SASLprep。

## 生命周期

`parseDataRowView()` 的字符串视图借用报文缓冲；消费或覆盖 ring buffer 前必须处理完。`PostgresCommandView` 借用 builder 的连续存储，builder 变更、移动、release 或析构后失效。

## 生产边界

当前没有 TLS/SSLRequest，因此不要把密码或查询通过不可信网络明文传输。需要 TLS 时应等待模块的独立 TLS 实现，而不是在调用侧跳过证书校验。
