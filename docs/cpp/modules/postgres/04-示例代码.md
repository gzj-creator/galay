# 04-示例代码

include 示例位于 `examples/cpp/postgres/include/`：

- `e1_query.cc`：同步查询
- `e2_async_query.cc`：异步查询
- `e3_pool.cc`：异步连接池
- `e4_prepared.cc`：prepared statement
- `e5_pipeline.cc`：pipeline

启用 `GALAY_ENABLE_CPP23_MODULES=ON` 且工具链受支持时，会构建 `import/` 下的对应版本。

```bash
cmake --build build --target \
  example_postgres_include_sync_query \
  example_postgres_include_async_query \
  example_postgres_include_pool \
  example_postgres_include_prepared_statement \
  example_postgres_include_pipeline
```
