# 01-架构设计

模块分为：

- `base/`：配置、错误、字段、行和结果集。
- `protoc/`：wire 消息编解码、SCRAM/MD5 认证和批量命令 builder。
- `async/`、`details/`：基于 kernel 状态机 awaitable 的非阻塞客户端和连接池。
- `sync/`：阻塞式客户端。
- `module/`：可选的 `import galay.postgres` facade。

服务端响应必须消费到 `ReadyForQuery('Z')` 才能安全复用连接。ErrorResponse 会保留 severity、SQLSTATE 和服务端诊断；查询错误之后仍读取到 `Z`。

所有 owning domain type 为 move-only，需要复制时显式调用 `clone()`。DataRow view 借用输入报文，仅在输入缓冲仍有效时使用。
