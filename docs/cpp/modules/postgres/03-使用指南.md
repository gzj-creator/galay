# 03-使用指南

## 同步查询

```cpp
galay::postgres::PostgresClient client;
auto connected = client.connect("127.0.0.1", 5432, "postgres", "secret", "postgres");
if (!connected) return 1;
auto result = client.query("SELECT 1");
```

## Prepared statement

先调用 `prepare(name, sql)`，再用 `execute(name, params)`。参数以 text format 编码，`std::nullopt` 表示 SQL NULL，空字符串与 NULL 不同。

## Pipeline

`pipeline(span<string_view>)` 连续发送 simple query；高级调用方可用 `PostgresCommandBuilder` 构造 `batch(span<PostgresCommandView>)`。`Query` 与 extended-query 的 `Sync` 分别形成一个 `ReadyForQuery` 边界。

## 连接池

优先使用 `lease()` 获取 `PostgresPoolLease`，其析构会把连接归还池。lease 不得比 pool 活得更久，同一 client 同时只允许一个 in-flight 操作。
