## 当前稳定事实

- `galay::mpmc`、`galay::mpsc`、`galay::spsc` 都提供 `BoundedChannel<T>` 与 `UnboundedChannel<T>`
- MPMC 有界与无界通道允许多个生产者和多个消费者并发访问
- MPSC 通道允许多个生产者并发发送，但调用方必须保证只有一个消费者
- `galay::spsc::UnboundedChannel<T>` 使用独立分块 SPSC 队列，允许一个生产者与一个消费者跨线程并发访问
