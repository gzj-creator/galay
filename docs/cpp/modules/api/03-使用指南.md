# 使用指南

## 统一注册

包括默认关闭文档模式在内，四种协议使用同一注册函数。下面 DTO 和 handler
来自 `examples/cpp/api/e1_users.cc`：

```cpp
template<class Builder>
galay::api::ApiResult<void> register_routes(Builder& builder)
{
    return builder.template add_api<galay::http::HttpMethod::GET,
        users::GetUserInput, users::UserDto>(
        "/users/:id", users::get_user,
        galay::api::Operation{.id = "getUser", .errors = {{404, "User not found"}}},
        galay::api::InputBinding<users::GetUserInput>{}
            .path<&users::GetUserInput::id>("id")
            .query<&users::GetUserInput::verbose>("verbose"));
}
```

应用创建 `HttpServerBuilder<>` 或 `HttpServerBuilder<true>` 等原生 builder，
检查注册、`build()` 和 `start()` 结果，并让 server 存活到控制循环退出。
开启模式可设置 `api_info` / `docs`，关闭模式没有这些接口，但请求行为不变。
需要同时监听多种协议时，对多个 builder 分别注册和构建，不复用已移动的 router。

这是未来 `.api` 生成器的边界：生成 DTO、handler 契约和注册函数，不另生成
绑定、编码、分发或 server。本次不实现解析器或生成器。

## 参数来源

serde 的 `REFLECT_FIELDS` / `reflect_fields` 一次登记外部字段名、description
和约束，schema 与编解码共用定义。字符串长度按 Unicode 标量计数。

- path 与 `:name` 一一匹配，required，不能为 optional。
- query 支持 string、整数、浮点、bool、登记 enum 和对应 optional。
- bool 仅接受 `true` / `false`；数值完整消费，不能溢出。
- 未绑定的字段组成 JSON object body，不重复 path/query；GET/HEAD 不允许剩余 body 字段。
- JSON body 要求 `Content-Type: application/json`；缺必需 body、畸形 JSON、重复键、未知字段或约束失败明确报错。
- 缺失 optional 保留默认值并校验；JSON null 清空 optional，query 文本 `null` 不代表空值。

JSON body 可包含数组和嵌套对象。query 数组、多值参数和 multipart 不在范围
内。query 复用 `HttpRequestHeader::args()` 单值 map，`+`、百分号、空值和重复
键继承现有 parser 行为，不执行第二次解码；需要精确保留分隔符或多值时用
JSON body。选择解码失败丢弃该次 input，不通过异常隐藏部分赋值。

typed 路径为无空段/尾斜杠的绝对路径，literal 使用 unreserved ASCII，参数
写为 `:name`。同形路径跨 method 使用相同参数名，operationId 全局唯一。
普通 route 不推导文档，wildcard 保留 native 优先级。

## 文档和离线导出

开启模式默认提供 `/openapi.json`、`/docs`、`/docs/`、initializer 和九项资源。
自定义路径：

```cpp
builder.docs({.spec_path = "/v1/schema.json", .ui_path = "/help/api-v1"});
```

路径必须为安全绝对 literal，不能包含参数、wildcard、空段或点段。文档及
资产路径自冲突、与任意方法的普通/typed 路由冲突都在构造 server 前失败。

```cpp
galay::http::HttpServerBuilder<true> builder;
builder.api_info({.title = "Users API", .version = "1.0.0"});
auto registered = users::register_api(builder);
if (!registered) return report_error(registered.error());
auto document = builder.export_openapi();
if (!document) return report_error(document.error());
```

不调用 `build()`，不创建 Runtime、不监听、不安装 UI、不读取 TLS 或资源文件。
关闭模式没有导出接口；离线导出在单独 `<true>` builder 上调用相同注册函数。

## 显式资源目录

```cpp
builder.docs({.spec_path = "/schema.json", .ui_path = "/reference"}, "/opt/app/api-ui");
auto built = builder.build();
if (!built) return report_error(built.error());
```

目录必须提供 API 参考中的完整九项文件。失败不创建 Runtime 或半注册路由，
不回退内嵌资源；修正目录或调用 `docs(config)` 切回内嵌后可重试同一 builder。
成功构建后 server 持有不可变文档和资源，移动/删除目录不影响当前进程，下次
构建仍需有效目录。请求期间不读文件、不热更新。

默认资源无需目录。Swagger UI 已编译进 `galay-api`，安装后不需要额外资源目录。
initializer 设置 `validatorUrl:null`、`persistAuthorization:false`、
`queryConfigEnabled:false`，没有在线 validator、持久授权、query 配置覆盖、
petstore 或 CDN 请求。应用自行指定的外部认证或链接不在离线承诺内。

## 协议与停止

TLS 使用原生证书、私钥和 CA 配置，生产保留 hostname/CA 校验。HTTP/2 工程
另链接 `galay::http2`；h2c 是 prior knowledge，浏览器直连 HTTP/2 使用 TLS H2
并确认 ALPN `h2`。HTTP/1 fallback 404 不代表 typed H2 的兼容入口。
HTTPS 是 HTTP/1 over TLS，不冒充 H2。

managed 启动尝试后不可重复；停止只停止当前实例。控制线程 `stop()` 先中断
网络 IO，排空请求后停 Runtime，重复调用无副作用。应用保证 handler 最终
返回并管理后台任务，不能从业务协程同步停止。
